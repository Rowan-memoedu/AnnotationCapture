# AnnotationCapture

基于 [eSearch 15.6.1](https://github.com/xushengfeng/eSearch/tree/15.6.1) 的截图批注归档工具，保留上游的截图、画笔、橡皮、撤销和编辑界面。

第一阶段新增按日归档、独立公式选区、纯笔迹导出及可替换的识别接口。实际 OCR 服务与 Math Academy 粘贴适配留待后续。

- 源码：D:/Projects/AnnotationCapture
- 应用数据：D:/AppData/AnnotationCapture
- 归档：D:/Artifacts/AnnotationArchive
- 构建与验收：D:/Artifacts/AnnotationCapture
- 缓存：D:/Caches/AnnotationCapture

运行数据、凭据和截图均不进入仓库。上游授权与署名保留于 LICENSE、README.eSearch.md 和上游源码；本项目继续采用 GPL-3.0。

构建：pnpm install；pnpm run build。交付与验收说明将在第一阶段完成后补齐。
