# AnnotationCapture

截图、批注、每日归档，并把选定的手写公式识别为 LaTeX，放入剪贴板。基于 [eSearch 15.6.1](https://github.com/xushengfeng/eSearch/tree/15.6.1) 的批注编辑器，保留画笔、形状、文字、橡皮擦、撤销和重做。

0.2.0 加入全屏画笔入口和邀请码登录，登录后统一使用管理员配置的 DeepSeek 服务。

0.3.0 修复落笔经过工具栏时误保存退出的问题，取消普通画布双击及右键退出。新批注默认红色画笔、隐藏放大取色框；支持滚轮调粗细、“保存为默认”、多种 OCR 输出格式，以及独立的区域 OCR 快捷入口。

0.4.0 加入公式画笔：手写后双击空白处转换为 STIX2 或 New Computer Modern，回填后继续批注，支持撤销、编辑 LaTeX 与重新排版。

0.4.1 取消批注画布的 Ctrl+C 截图响应，避免划词软件注入复制键时打断书写；需要复制截图时点击工具栏，画布保持打开。文字输入框仍支持 Ctrl+C，按 Esc 才归档退出。鼠标移动每帧合并处理，隐藏放大框时停止像素采样；加入每日自动检查、下载和覆盖更新。

0.4.2 新增 D 键自由圈选与按住清除；公式画笔移至左侧操作栏，公式操作按所选工具显示，完成操作栏采用紧凑分组布局。

0.4.3 的自由圈选默认“圈到部分笔迹即选中”，可在设置中切换为“全部圈住笔迹才选中”。两种规则同时用于 D 键圈选和按住 D 清除，移动或删除以整条笔迹为单位。单击托盘打开设置；截图和区域 OCR 使用快捷键或托盘右键菜单。

0.5.0 加入 Math Academy 公式输出。按网页实际使用的 MathQuill 输入器适配分数、根号、上下标、函数、积分与求和；移除不兼容的纯排版标记，不改变数学表达式。不兼容的多行、矩阵或未知命令保留原始结果并提示，不自动复制。

## 下载与使用

访问 [静态下载页](https://rowan-memoedu.github.io/AnnotationCapture/) 查看下载、快捷键和使用边界。

从 [Releases](https://github.com/Rowan-memoedu/AnnotationCapture/releases) 下载 `AnnotationCapture-0.5.0-windows-x64.zip`，解压到可写目录，运行 `AnnotationCapture.exe`。运行时已随包提供，无需安装 Node.js、Python、pnpm 或 OCR 模型。当前发行目标是 Windows x64；包未做商业代码签名。

1. 按 `Alt+W`，或点击“全屏批注”：截取鼠标所在显示器，直接进入画笔。按 `Ctrl+Alt+S`，或点击“区域截图”：框选后自动切换画笔，在选区上继续批注。
2. 按 `Esc` 或 `Ctrl+Enter`：保存带批注的截图后退出。正在落笔时会等抬笔再保存。
3. 按 `Ctrl+Shift+Enter`，或点击“选区识别”：先归档完整截图，选择输出格式，框选公式、文字或图示，再点击“识别选区”。只发送选区内的批注笔迹，网页背景不会发送给识别服务。
4. 成功后，LaTeX 文本进入剪贴板，结果窗口同时展示输入图和可编辑的识别结果。若等待期间剪贴板发生变化，会保留结果供手动复制。

两种截图快捷键均可在设置中修改。区域模式只保存选定区域；全屏模式保存当前显示器完整画面。公式选择期间按 `Esc` 会退出，已经归档的截图仍保留。保存失败会显示错误并保留画布，修复归档目录后可重试。

设置中的默认颜色、粗细和“批注时显示放大框”对全屏、区域两种批注入口共同生效。普通滚轮向上加粗、向下变细，Shift+滚轮每次调整 5 px；Ctrl+滚轮保留缩放。工具栏“保存为默认”保存当前画笔颜色和粗细；未保存的临时调整只影响本次批注。连续书写、双击画布或抬笔经过工具栏不会触发归档。

按 `Ctrl+Alt+O` 或点击“区域 OCR”，框选结束后直接识别选区画面并复制，不进入批注。默认自动判断普通文字、Markdown、Mermaid 图或数学公式，公式使用 `$…$`。该入口会发送选中的屏幕内容；只框选需要识别的区域。快捷键可在设置修改。

批注后的 OCR 可选自动判断、普通文字、Markdown 文字、`$…$` 公式、原始 LaTeX、Math Academy 公式、`$$…$$` Markdown 公式（RemNote / Obsidian）和 Mermaid 代码块。每个任务保留所选格式，重试不改变格式。这个选区识别入口输出到结果区和剪贴板，独立于公式画笔。

## Math Academy 公式输出

批注后按 `Ctrl+Shift+Enter`，在输出格式中选择“Math Academy 公式”，框选需要输入的一条公式并识别。也可在设置中将它设为默认输出格式。结果复制完成后，点击 Math Academy 网页里的公式输入框，再按 `Ctrl+V`，核对显示后自行提交。

输出使用输入器直接接受的 LaTeX，不带 `$` 或代码围栏。适配会去掉 `\displaystyle` 和数学间距标记，将 `\dfrac`、`\tfrac` 统一为 `\frac`；保留字母大小写、上下标、分数层级和粗体等数学内容。格式转换在本机完成，不需要浏览器扩展，也不会自动填写或提交答案。

遇到多行 `aligned`、矩阵、`\mathbb` 等未支持结构时，不改写为另一种数学含义，也不覆盖剪贴板。结果区保留原始 LaTeX 和具体提示，可编辑后点击“复制到 Math Academy”，或重新选择原始 LaTeX 输出。识别原文同时保存在归档结果中。网页输入器日后变化时需重新验证兼容性。

## 自动更新

0.4.1 起默认每天检查一次本仓库的已发布 Windows x64 ZIP，包含当前预览版通道；关闭软件期间不另起常驻进程，下次启动补查。设置页可关闭自动更新、立即检查，或手动安装已经下载的新版。

新版通过 GitHub 提供的 SHA-256 和包内文件清单校验后暂存。正在批注、识别或使用设置页时延后自动安装；空闲时退出、覆盖原程序并重新启动，保留登录、设置、归档和程序目录中的其他用户文件。启动健康检查失败会恢复旧程序并重启；回滚副本保存在用户数据目录的 Updates 中，至少保留 14 天。

第一次从 0.4.0 或更早版本升级，仍需完整解压 0.4.1 ZIP 覆盖原程序目录；之后可以自动更新。ZIP 中的 `program-manifest.json`、`resources` 等程序文件须完整保留，不能只替换 EXE。程序目录须可写，更新时需至少 2 GB 可用空间。网络或校验失败不会改动现有程序，可稍后手动重试。

## 公式画笔

在任意批注模式的左侧操作栏点击“ƒx”（公式画笔），直接手写一条公式。“转换公式”和“选区识别”仅在选中公式画笔后显示，切回普通画笔时收起。写完后双击画布空白处，或按 `Ctrl+Shift+T`，或点击“转换公式”。软件识别本条公式的纯笔迹，用本机随包提供的字体排版后替换原笔迹，继续保持批注状态。普通画笔的双击行为仍不转换、不退出。

默认字体为 STIX2，可在设置中选择 New Computer Modern。转换沿用原笔迹颜色和位置，按原范围等比例排版；不改变剪贴板、不提前归档。识别期间可以继续写下一条公式。识别或排版失败会保留原笔迹，点击“转换公式”可以重试。

转换后可一次撤销回原笔迹，重做恢复排版。切到“移动”工具选中公式，可移动、缩放，在公式编辑区修改 LaTeX 或字体并点击“更新公式”；此处重新排版不调用识别服务。请核对识别出的字母大小写、上下标和结构。

按 Esc 时取消未完成的转换，保存当时可见的批注并退出。已转换公式及原始笔迹源数据随截图保存在 `annotations.json` 中；当前版本尚无重新打开整个归档画布的入口。

## 自由圈选与快捷清除

按住 `D`，用鼠标或数位笔沿自由边界圈住笔迹，抬笔即删除完全圈入的笔迹；松开 `D` 恢复普通画笔。一次按住可连续清除多处，`Ctrl+Z` 可撤销。

单击 `D` 进入普通自由圈选。圈中多笔后可一起拖动，按 `Delete` 删除，移动和删除均可撤销、重做。再次单击 `D` 恢复普通画笔。圈选不会改变截图归档范围；文字输入时 `D` 仍用于正常打字。

## 从旧版覆盖升级

1. 完成当前批注，从系统托盘右键菜单选择“退出”。关闭设置窗口只会留在后台，不能代替退出程序。
2. 将新版 ZIP 的全部内容解压到原来的程序目录，选择覆盖同名程序文件；保持 `AnnotationCapture.exe` 路径不变。不要先删除旧目录，也不要删除或替换 `AnnotationCapture-data`。
3. 重新运行原来的 `AnnotationCapture.exe` 或桌面快捷方式。历史归档、自定义归档目录和原快捷键继续保留。0.3.0 新增的默认颜色、粗细和放大框设置首次采用红色、2 px、关闭，之后使用自己保存的默认值。

从 0.1.1 升级后，首次识别须使用邀请码登录，此后自动恢复登录，不再填写个人 API。已在 0.2.0 登录的用户再次覆盖更新仍保留本机登录状态。使用 `--userData` 或 `--archiveRoot` 的用户继续使用原快捷方式及参数。

已在本机使用 0.1.1 正式 ZIP 验证上述两种数据目录的覆盖升级，并逐文件核对归档哈希。快捷键若被其他程序占用，设置中会提示具体入口，可换一个组合；另一可用快捷键仍保留。

## 邀请码登录

首次使用公式识别，在软件中输入管理员提供的个人邀请码。登录状态由 Windows 加密保存在本机，后续启动自动恢复。个人邀请码可用于自己的多台电脑；管理员可单独停用一个用户，该用户所有设备的登录随之失效。

所有登录用户使用管理员配置的统一识别服务，无需填写 API Key 或模型。发行包不包含上游 API 密钥；登录凭据只用于访问独立网关。批注 OCR 只发送选中笔迹；区域 OCR 只发送选中的屏幕画面，不额外发送选区外的内容。

旧版保存的个人密钥及 DeepSeek 环境变量不会用于 0.2.0 的识别请求。离线时保留本机登录状态，服务恢复后可重新连接。

未登录或统一服务尚未配置时，截图归档与公式图导出仍可使用，剪贴板保持原样。请求失败或超时会显示状态，可在结果卡上重试。管理员配置见 [网关运维说明](gateway/README.md)。

## 保存内容

默认数据目录为程序旁的 `AnnotationCapture-data`。归档位置可以在设置中更换，默认是该数据目录下的 `Archive`。每次完成批注后生成独立目录：

```text
Archive/YYYY-MM-DD/<截图编号>/
  capture.png       带批注的完整截图选区
  capture.json      截图尺寸、屏幕、时间与完整性记录
  annotations.json  画布对象、公式 LaTeX / 字体及原始笔迹源数据
  formula-*.png     单独框选的纯笔迹图
  formula-*.json    识别状态与结果
```

日期按电脑本地时区划分。不会自动删除历史归档。公式识别不会缩小或覆盖 `capture.png`。结果列表展示当前运行期间的任务；重启后，原始图和结果仍可从归档目录查看。

可用 `--userData <绝对路径>` 和 `--archiveRoot <绝对路径>` 指定独立数据/初始归档目录；`--input <图片路径>` 可导入图像进行批注。归档目录一旦在设置中保存，以设置为准。

## 当前边界

- 输出支持普通文字、Markdown、Mermaid 和公式；Math Academy 输出需手动粘贴到网页公式框，未提供自动粘贴和答案提交。
- 公式画笔识别需要登录及联网；排版、修改字体与 LaTeX 使用随包资源。排版支持常见数学命令，不支持外部资源、自定义宏及系统字体任意切换。
- 识别仅转写选定公式，不求解，不自动纠正数学表达式。结果可在复制前后人工检查、编辑。
- Esc、归档按钮和批注窗口的常规关闭会先保存；保存失败时保留画布。托盘“退出”及设置页“退出软件”直接结束，不等待归档，本次尚未保存的批注会被放弃。
- 此版本集中提供截图批注、归档和公式识别。上游的录屏、滚动截图、搜索和贴图功能未作为本发行版入口开放。

## 构建与验收

使用 Node.js 24 和 pnpm 10.17.0：

```powershell
pnpm install --frozen-lockfile --ignore-scripts
node node_modules/electron/install.js
pnpm run typecheck
pnpm test
pnpm run release:win
```

`ANNOTATION_ARTIFACTS` 可指定打包暂存与发行产物目录；本项目开发环境默认使用 `D:/Artifacts/AnnotationCapture`。发行包与源码独立，不引用开发机器的 `node_modules`。

`scripts/capture-modes-acceptance.cjs` 核对两种入口、默认画笔及归档像素；`scripts/invite-login-acceptance.cjs` 验证真实网关登录、重启、多设备及单用户撤销；`scripts/ui-acceptance.cjs` 验证真实截图、绘画、归档与未登录状态；`scripts/edge-acceptance.cjs` 验证最后一笔、撤销重做、橡皮擦、保存失败、选区取消、文字编辑和 100%/150%/200% 显示缩放。`scripts/live-ocr-acceptance.cjs` 通过私密的 `ANNOTATION_INVITE_FILE` 登录，使用统一 API 做四个真实笔迹样例；客户端无需上游密钥。

脚本需要 Playwright，可通过 `PLAYWRIGHT_MODULE` 指向模块目录；实际使用软件不需要 Playwright。设置 `ANNOTATION_EXE` 可针对打包后的程序执行相同验收。`pnpm run test:gateway` 运行隔离网关测试，使用本机假上游验证协议与权限，不计为真实模型识别通过。

`scripts/upgrade-acceptance.cjs` 从旧版正式 ZIP 启动，在同一程序路径覆盖新版，检查默认/自定义数据目录、原归档哈希、设置、首次邀请码登录及重复覆盖后免登录。需要分别指定旧、新 ZIP 和私密邀请码文件，可通过 `ANNOTATION_OLD_ZIP`、`ANNOTATION_NEW_ZIP`、`ANNOTATION_INVITE_FILE` 配置。

`node scripts/accept-release.cjs` 将当前版本 ZIP 解压到新的隔离目录，执行独立启动、两种截图模式及编辑边界。提供 `ANNOTATION_INVITE_FILE` 时增加四个真实 OCR 样例；缺少该项时报告明确保留真实 API 待验收状态，不标记为可正式发布。完成实际屏幕捕获后才将绘画窗口移到可见桌面之外；识别的预期答案只用于验收比较，不发送给模型。
