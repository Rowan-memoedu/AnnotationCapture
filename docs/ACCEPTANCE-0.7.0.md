# 0.7.0 验收

## 快速白板

操作栏新增“快速白板”，没有新增快捷键。自动检测默认开启，矩形上限默认 5、可设置为 1–20；任务栏和窗口顶部默认允许覆盖。关闭检测后，不发送页面预览，使用中央白板。

中央白板可移动，并通过四角与四边中点调整宽高；控制点扩大到 18 CSS 像素，触摸范围为 32 CSS 像素。调整只改变白色背景，笔迹保持原位。白板不参与 D 键清除或普通圈选删除；明确收起时保留笔迹，撤销可恢复白板身份。

检测未完成、失败或没有可用结果时，点击立即创建中央白板；迟到结果不替换它。检测成功生成固定矩形，不进入移动或缩放状态。公式识别把全部白板内笔迹按原位置合为一张图，屏蔽白板之外和矩形间隙，空白白板拒绝识别。

实际 Electron 输入检查覆盖 100%、150%、200% 显示缩放下的移动、单轴和双轴缩放、D 与 Delete 保护、收起和撤销、延迟结果、非法坐标回退、空白识别拒绝、多白板合并和保存失败恢复。图像与绘图层尺寸统一，避免在截图物理像素上重复进行 Retina 放大；额外检查不同图像尺寸下两层的实际显示边界一致。原有压感画笔在三档缩放下保持轻重笔宽 10/20、鼠标等宽 14/14 的检查结果。

## 真实空白识别

通过现有网关和真实模型，以合成课程页面及独立的笔记页面作为输入，覆盖任务栏、窗口顶部允许覆盖和禁止覆盖两种设置。期望坐标和正文边界仅用于本地验收，不进入模型提示词。检查生成数量、固定状态、可写面积和已知正文区域的遮挡情况。

开发复测发现低输出预算会在推理阶段耗尽，快速模式会误判图表边界，因此保留已配置的模型推理模式、增加输出预算，并对返回坐标向内留出截图短边 1% 的安全距离。检测在后台运行，服务超时或异常时保留立即创建中央白板的路径。最终参数通过源码和独立包各三组真实调用，均未覆盖测试正文或受保护区域，可写面积约占页面 40%–58%，耗时约 7–45 秒。LLM 仍可能误判其他页面，可收起白板查看原文；这些样例不代表任意页面的识别准确率。

页面预览最长边不超过 1600 像素。网关沿用邀请码会话、并发和调用限额；不把请求图像、凭据或模型响应写入日志。其他 OCR 回归关闭空白检测，避免额外发送测试范围以外的页面截图。

## 启动与退出

批注窗口在后台提前加载，开始批注时再获取当前截图。正常退出先隐藏窗口，再完成归档；若仍按住笔尖，则等抬笔后执行，以保留最后一笔。保存成功才销毁画布，失败则恢复窗口。预加载的新窗口不沿用上次笔迹或存档标识。

实现参考了 [FocusTool 的交互模式切换](https://github.com/YaRus02/FocusToolWin/blob/main/Services/InteractionModeTransitionController.cs)与[落笔期间的退出处理](https://github.com/YaRus02/FocusToolWin/blob/main/Services/PushToAnnotateController.cs)，以及 [Electron 隐藏窗口与后台节流接口](https://www.electronjs.org/docs/latest/api/browser-window)。没有复制 FocusTool 源码。

使用同一合成截图比较新建窗口和预加载窗口，检查可书写时间而非仅检查窗口出现。最终独立包各测四次，取排序后上中位数，从约 450 ms 降至 194 ms。延迟保存测试人为增加 1.5 秒后端耗时，三档缩放下前端分别约 10、10、12 ms 内隐藏，画布保持到保存结束。此时间来自隔离自动化输入，不包含真实热键硬件和显示器延迟。

## 检查与发行

类型检查、Lint、94 项单元测试和网关 14 项测试通过。独立 Windows ZIP 的 38 个回归阶段全部通过，覆盖设置、三档缩放下的白板、压感、圈选与公式画笔，以及归档、连续书写、剪贴板、输出格式和真实模型调用。实际设置页及下载页的窄宽屏布局检查通过。压感使用自动化输入验证，尚未用真实压感笔硬件验收。

首轮失败和复测记录分别保留。Windows 事件日志确认了测试期间的虚拟内存不足；相关超时、崩溃项目在清理隔离测试进程后通过。150% 缩放下，Fabric 选中组和取消选中后的边缘栅格化不同，几何测试改为比较相同的取消选中状态，保持原有逐像素容差及存档坐标检查。另一次系统剪贴板读回不一致，原校验复测通过；文字、Markdown、公式和三类图表输出均完成实际剪贴板读回。复测期间发行 ZIP 未改变。

八个真实公式转写样例的功能链路均通过，其中四个精确匹配；其余四个存在 `x/X` 大小写差异。普通笔迹、公式画笔、自由选区的另三组识别，以及公式画笔回填的三组识别，各有两组精确匹配。原笔迹保留、结果可编辑，功能通过不等于任意公式均能准确转写。

本机已通过更新器升级至 0.7.0，73 个程序文件校验一致，更新健康回执与持续运行进程版本一致；登录、设置和全部既有归档文件比对未变，保留 14 天回滚材料。发行同时提供 Windows 独立 ZIP、对应标签源码、构建信息及 SHA-256 校验文件。
