# 0.4.3 验收

## 自由圈选规则

- 默认“圈到部分笔迹即选中”；既有设置文件没有该字段时同样使用此默认值。
- 设置中可切换为“全部圈住笔迹才选中”，保存并重启后保留；非法值会拒绝保存。
- 两种规则同时作用于单击 D 圈选和按住 D 清除。圈住部分后选中或删除整条笔迹，不裁断笔迹。
- 全屏、区域批注分别验证两种规则的选中删除、按住清除，以及保留圈外笔迹。
- 在 100%、150%、200% 缩放下，分别完成圈选、拖动、撤销重做、Delete 删除、指针取消和笔输入事件验收。
- 几何测试覆盖两端都在圈外但中间穿过圈内的线段、笔画宽度、边界接触、凹多边形与包围盒误选。

## 托盘与设置

- 触发实际托盘点击监听器，只显示设置窗口，不创建截图窗口。
- 设置页已移除“区域截图、全屏批注、区域 OCR”三个启动按钮，三个全局快捷键仍注册。
- 自由圈选下拉框在 320、375、414、768、1440 像素宽度下无横向溢出，文字完整显示；实际 Electron 截图已检查。
- 修复单屏环境下截图接口返回空显示器 ID 的兼容问题：只有一个系统显示器及一个匿名截图源时才允许匹配，多屏不按顺序猜测。
