# 0.4.0 验收范围

公式画笔已接入截图批注编辑器。工具栏选择“公式画笔”，写完一条公式后双击空白处、按 Ctrl+Shift+T 或点击“转换公式”，识别后按 STIX2 / New Computer Modern 原位回填，保持批注状态。最终剪贴板 OCR 的格式选择与此功能独立。

## 独立程序验收

Windows x64 ZIP 解压到隔离目录运行，未借用源码目录的运行时或依赖。27 项客户端测试、12 项网关测试及 19 个独立包功能阶段通过。

| 检查 | 结果 |
| --- | --- |
| 全屏、区域入口 | 都可启用公式画笔；普通画笔双击不识别、不退出 |
| 双击边界 | 移除本次双击产生的两个点，保留之前书写的小数点；不会把点击工具栏当成落笔 |
| 排版位置 | 100%、150%、200% 缩放下按可见笔迹范围等比例回填；已修复 Fabric 默认中心原点造成的偏移 |
| 本地字体 | 两种字体都生成自包含 SVG 路径；排版窗口阻止网络请求，不依赖 CDN 或系统字体安装 |
| 默认值 | 字体、颜色、笔宽设置保存后生效；普通画笔与公式画笔共用颜色、粗细 |
| 撤销与编辑 | 一次撤销恢复原笔迹，重做恢复相同画面；移动工具选中公式后可修改 LaTeX / 字体，本地重新排版不再次 OCR |
| 连续书写 | 识别期间可写下一条公式，重复触发同一组不重复请求，两组结果分别回填 |
| 过期结果 | 源笔迹被删除、撤销或改变后，迟到结果不会覆盖当前画布 |
| 失败与退出 | 识别失败、无效 LaTeX 保留原笔迹；Esc 取消待完成请求，保存当前可见内容并退出，不等待 OCR |
| 归档 | capture.png 保留最终画面，annotations.json 保存画布对象、LaTeX、字体及原笔迹源数据 |
| 剪贴板 | 公式回填不改变剪贴板；原有选区 OCR 仍输出到剪贴板 |

每种缩放均运行完整公式画笔交互检查，包含只发送数位笔事件、不补发兼容鼠标事件的书写和双击。另运行数位笔四方向框选、取消后重选、隐藏窗口恢复、鼠标与区域 OCR 回归。实体数位板硬件尚未单独验收。

保留了首次候选包的失败记录：缩放验收发现回填原点偏移后修复通用坐标处理，再重新构建并验收新的独立包，没有将失败包发布。

## 真实识别

使用邀请码登录，通过现有统一 DeepSeek 网关识别合成手写样例。预期答案只参与验收比较，不传给模型。最终独立包回填结果：

| 样例 | 字体 | 结果 |
| --- | --- | --- |
| x²+1=0 | STIX2 | 规范化后精确匹配，回填后仍在批注 |
| √(x+1) | New Computer Modern | 规范化后精确匹配，原笔迹源数据保留 |
| X+x=2 | STIX2 | 保留大小写并精确匹配 |

这轮公式画笔为 3/3 匹配。早期回填测试以及原有剪贴板 OCR 回归仍出现过 x / X 歧义；原始失败记录保留。最终六个剪贴板公式样例中三个匹配，另外三个存在大小写差异。功能验收通过不代表每张笔迹图都能精确转写。软件不自动改字母大小写，保留可编辑 LaTeX、原笔迹与撤销入口，提示核对大小写和上下标。

普通文字、Markdown、单美元公式、Mermaid 自动分类，以及两种 Mermaid 图示的节点、边和渲染回归通过。

## 覆盖升级与分发

旧版退出后，把新版 ZIP 全部解压到原程序目录覆盖同名文件，保留 AnnotationCapture-data、自定义归档目录和原快捷方式参数。0.1.1 首次识别仍需邀请码；0.2.0 / 0.3.0 的有效登录沿用。

已分别从 0.1.1、0.2.0、0.3.0 正式 ZIP 验证默认数据目录和外置数据目录，共六条覆盖升级路径。原归档和用户自建文件逐文件哈希一致；设置、登录会话及重复覆盖后免登录均通过。

发布提供 Windows ZIP、对应标签源码 ZIP、SHA256SUMS.txt 和 build-info.json。发行包扫描排除了用户数据、登录配置和上游 API 密钥，无外部 node_modules 依赖。版本仍为未做商业代码签名的 Windows 预览版。

Math Academy 专用输出、任意系统字体切换、从归档重新打开整个编辑画布仍不在此版范围内。
