# 0.7.1 验收

## 白板入口和调整

白板入口位于左侧工具栏、公式画笔下方。底部操作栏保留调整、收起、识别和状态提示，取消底部重复的创建入口。

中央白板创建后立即进入调整状态：内部拖动移动，四边任意位置可单轴缩放，四角可双轴缩放，点击“完成调整”恢复书写。生成失败或尚未返回时创建的中央白板也遵循这一规则。LLM 生成的白板始终固定，没有调整入口。背景调整不改变笔迹位置；白板仍受 D 键和圈选删除保护。

源码和独立包均在 100%、150%、200% 缩放下检查了上述交互、全边框命中、收起撤销、延迟结果不替换中央白板、多白板笔迹合并、空白拒绝识别和保存失败恢复。

## 空白识别提速

模型仅返回需要保护的内容位置；完整侧栏、卡片、图表和表格单独定位，正文按段落与分栏分组，任务栏与窗口顶部单独分类。程序根据用户设置决定保留哪些区域，计算面积优先且互不重叠的矩形。客户端根据预览图的对比边缘进一步缩小候选范围，避免模型边界偏差覆盖文字或图表边线。

页面预览最长边为 1024 像素。空白检测单独关闭 DeepSeek 推理，输出预算为 1200 token，上游超时为 10 秒；公式 OCR 的模型配置不变。配置依据 [DeepSeek 推理模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。客户端为相同页面、设置和登录会话缓存一分钟，最多八项，离开批注后正在进行的有界请求可完成并供再次进入复用；请求失败不缓存。

## 验收记录

类型检查、Lint、98 项单元测试及网关 15 项测试通过。单元测试包含浅色与深色内容边缘保护、允许覆盖的窗口区域、相同页面复用、取消后复用、设置与会话隔离、失败与过期后重新请求。

真实模型测试使用合成课程页、笔记页、深色仪表盘和双栏文档。已知内容边界仅用于本地检查，不进入提示词；检查固定状态、最多五块、零正文遮挡、至少 15% 页面可写面积和生成耗时。早期试验中的任务栏遗漏、边线误差、侧栏误判及可写面积不足均保留失败记录，分别通过分类定位、本地边缘检查、独立内容分组和减少重复边距修正。

最终独立包六组调用全部通过。五组非缓存调用从触发到区域就绪约 2.33–3.19 秒，包含约 0.83–1.17 秒的测试窗口初始化；画布就绪后的检测等待约 1.43–2.20 秒。同图缓存调用总计约 1.39 秒，其中检测等待约 0.29 秒。生成 3–5 块固定白板，可写面积约占页面 21.6%–53.4%，与已知正文和禁止覆盖的窗口区域重叠面积均为零。这些受控样例不代表所有页面的识别准确率。

独立 Windows ZIP 的 38 个回归阶段全部通过。首轮失败与复测记录分别保留，期间 ZIP 未改变。三个旧输入测试改为等待画布实际就绪后再操作，原操作和断言保留；缓存检查分别记录冷窗口初始化与检测等待，要求后者不超过 1.5 秒，所有样例总耗时不超过 8 秒。压感撤销与两个剪贴板读回项目按原断言复测通过。真实压感笔硬件尚未验收。

公式 OCR 功能链路通过，八个公式转写样例中三组精确匹配，其余存在 `x/X` 大小写差异。原笔迹与可编辑结果保留；本次没有修改公式 OCR 提示词和推理配置。

本机已通过更新器升级到 0.7.1，健康回执与运行程序版本一致，73 个程序文件校验通过。登录、设置和 770 个既有归档文件比对未变，保留 14 天回滚材料。发行提供独立 Windows ZIP、对应标签源码、构建信息与 SHA-256 校验文件。
