# 0.3.0 验收范围

本版修复了跨工具栏抬笔导致误归档退出的问题，新增统一画笔默认值、区域 OCR、多种 OCR 输出格式和立即退出。公式画笔的字体回填仍是独立设计，Math Academy 专用输出仍未接入。

## 批注与退出

| 检查 | 结果 |
| --- | --- |
| 旧版故障复现 | 0.2.0 在画布起笔、关闭按钮处抬笔，会保存并退出 |
| 全屏与区域连续书写 | 两种入口各连续 40 笔，抬笔经过关闭、复制、保存、识别按钮及快速双击，均保持画布，不提前归档 |
| 主动完成 | Esc 生成一份带笔迹的归档；区域模式保留区域范围，全屏模式保留当前显示器范围 |
| 默认外观 | 红笔，批注时不显示放大框；两项在设置中可更改 |
| 默认画笔 | 滚轮调粗细，工具栏保存当前颜色与粗细，全屏和区域入口共同加载；临时修改不覆盖已保存默认值 |
| 立即退出 | 托盘与设置页调用同一立即退出函数；正常状态和保存目录不可写时均在 1 秒内结束，不等待归档 |
| 保存失败 | Esc 保存失败时仍保留画布；立即退出会放弃当前未保存批注 |
| 编辑边界 | 最后一笔、撤销重做、橡皮擦、保存失败重试、取消选区、文字编辑及三种显示缩放通过 |

退出验收通过应用 IPC 调用与托盘绑定的同一函数，核对了进程退出码和退出时间；没有把关闭设置窗口当成退出软件。

## OCR 输出

管理员统一 DeepSeek 服务通过邀请码会话调用；下载包不含上游密钥。最终批注 OCR 支持选择格式，区域 OCR 在框选后自动分类并复制。两个入口使用不同的图像来源：批注入口只发送选中笔迹，区域 OCR 发送所选画面。

| 输入与模式 | 检查 |
| --- | --- |
| 批注 → 原始 LaTeX | 多项式、分式、根式、混合大小写，检查内容与剪贴板一致 |
| 批注 → Markdown 公式 | 分式、根式，输出为恰好一层 `$$` 显示公式，保留原表达式 |
| 批注 → Mermaid | 单向连接、双分支，检查节点标签与有向边；使用 Mermaid 12.2.0 解析并生成 SVG |
| 区域 OCR → 普通文字 | 合成屏幕原文样例，自动分类为 text，逐字内容与剪贴板一致 |
| 区域 OCR → Markdown | 标题、分节、列表样例，自动分类为 markdown，保留文字与层级 |
| 区域 OCR → 公式 | 分式样例，自动分类为 formula，保留大小写并使用单层 `$…$` |
| 区域 OCR → Mermaid | 方框和有向箭头样例，自动分类为 mermaid，验证箭头方向与 SVG 渲染 |

区域 OCR 样例以合成图像导入真实编辑器，框选后走同一自动识别链路；批注样例在真实 Fabric 编辑器中用鼠标绘制。预期结果只用于验收比较，不发送给模型。Markdown 验证的是输出格式与公式内容；没有向用户的 RemNote 或 Obsidian 写入验收内容。

大小写歧义采用“自动复制后核对”：一张合成分式样例中的两条交叉直线曾被识别为大写 `X`，而测试预期为小写 `x`；原始像素回放也返回 `X`。该样例缺少区分大小写的可靠字形线索。失败记录保留，功能链路通过不等于转写精确匹配。软件保留输入图、识别原文和可编辑结果，用户可核对后改写并重新复制；不会把模型返回自动统一为大写或小写。

## 升级与分发

- 独立 Windows x64 ZIP 包含 Electron 运行时，PATH 仅保留 Windows 系统目录时仍可运行。
- 0.1.1 和 0.2.0 的原目录覆盖升级分别验证程序旁数据、自定义数据目录；历史归档及用户文件按哈希核对。
- 0.2.0 的登录状态应在升级后保留；0.1.1 首次使用邀请码登录。重复覆盖不清空登录状态。
- 画笔默认值新增字段首次为红色、2 px、放大框关闭；随后使用用户保存的设置。
- TypeScript、Biome、24 项客户端测试与 12 项网关隔离测试通过；Linux 部署也运行网关测试，并核验独立 OCR 服务和原学习服务均健康。
- 本机验证与其他设备兼容性、GitHub CI 分别报告。本版仍为未做商业代码签名的 Windows x64 预览版。
