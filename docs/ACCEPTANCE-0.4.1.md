# AnnotationCapture 0.4.1 验收

批注画布不再响应 Ctrl+C，避免划词软件注入复制键时反复合成截图、写入剪贴板或中断书写。需要复制截图时点击工具栏，复制后继续批注；文字输入框仍可正常 Ctrl+C。Esc 仍归档并退出。本版同时加入每日自动检查 GitHub Releases、下载校验、空闲覆盖更新和失败回滚。

- 应用类型检查、代码规范检查与 31 项单元测试通过。
- 正式独立 ZIP 解压后的程序通过 21 个功能阶段，包括区域和全屏批注、持续书写、复制后继续画、数位笔事件、三种缩放下的公式画笔、归档失败重试、立即退出和真实 DeepSeek OCR。
- 全屏和区域模式各连续画 120 笔，每笔后发送 Ctrl+C，截图编码与剪贴板写入次数为 0，归档保留全部 120 条笔迹。1000 次鼠标移动的像素采样由 1000 次降为隐藏放大框时 0 次、显示时 1 次；该隔离测试中两种模式的画面帧间隔第 95 百分位均约为 16.8 毫秒。该数字是本机受控测试结果。
- 更新安装器通过 6 项边界检查：合法包、目录穿越、夹带用户数据、内容不符、额外程序文件和本地程序被修改。
- 同一正式程序在隔离目录内完成模拟后续版本的实际升级：批注中可以下载但延后安装；覆盖后通过启动确认；登录、设置、归档及其他用户文件保留；关闭自动更新后重启仍保留设置。新版启动失败时，恢复并重新启动旧版。测试路径包含中文、空格和 `&`。后续版本号仅用于本地 fixture，没有发布。
- 0.4.0 到 0.4.1 的便携数据和外置数据两条路径均通过覆盖升级与再次覆盖检查。已有归档哈希、快捷键、个人文件和登录保留。

数位笔测试使用 Chromium 的 pen 指针输入并禁止兼容鼠标消息，实体数位板仍需在实际设备上确认。真实 OCR 的功能链路与文本精确度分别报告：6 个最终公式输出样例中 3 个精确匹配，另外 3 个出现已知的 `x/X` 歧义；3 个回填样例中 2 个精确匹配。原始识别结果如实记录，保留手动核对与修正入口。

每日检查在软件运行时进行；软件关闭期间不额外常驻，下次启动补查。自动安装会避开批注、识别以及正在使用的设置页。旧于 0.4.1 的用户需先手动完整覆盖一次，之后才具备自动更新能力。
