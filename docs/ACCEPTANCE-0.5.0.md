# 0.5.0 验收

## Math Academy 实际输入

使用已打开的 Math Academy 课程页面，检查网页加载的 [MathEditor](https://www.mathacademy.com/js/math-editor.js) 与 [MathQuill](https://www.mathacademy.com/js/mathquill.v2.1.min.js)。逐项粘贴应用通过真实任务、归档与剪贴板链路产出的文本，再从页面输入器回读 LaTeX；未提交练习答案，测试后恢复空输入框。

11 组公式结构核对通过：分数排版指令清理、带下标的嵌套根号与分数、复合指数、带间距的积分、求和、函数与对数、二项式系数、希腊字母、不等式、正体与粗体、集合括号。比对只消除空白、单字符参数花括号及 MathQuill 的等价命令别名，不消除数学项或上下标。

实测原始 `\displaystyle`、数学间距命令、多行 `aligned` 和 `\mathbb` 可造成整个输入结果为空。客户端仅清理已确认可移除的排版指令；未支持的结构或命令保留原始 LaTeX，显示原因并停止自动复制。转换没有调用模型改写、求解或简化。

## 应用链路

- 设置与选区弹窗均可选择 Math Academy，默认格式保存后重启保留。
- 识别网关仍接收原始 LaTeX 请求，转换在本机完成。任务保存原始识别结果、转换文本和格式。
- 自动复制、手动编辑后重新校验复制、重试保持格式、不兼容结果保留和识别期间剪贴板变化保护均通过。
- 原始 LaTeX 输出继续允许多行内容，不受 Math Academy 兼容限制影响。
- 结果区在 320、375、414、768、1440 像素宽度下无横向溢出，操作按钮文字不换行，成功、处理中、不兼容和可编辑状态使用实际 Electron 页面核验。
- 类型检查、Lint 和 77 项单元测试通过。新增 `scripts/math-academy-acceptance.cjs` 使用隔离本地网关验证确定性格式、UI 和剪贴板行为；该步骤不计为真实 OCR。

## 独立包与真实识别

冻结的 Windows x64 ZIP 通过 28 个验收阶段；解压后运行的应用与发行包校验一致。100%、150%、200% 显示缩放下的批注、D 键自由框选、公式画笔、更新与数据保留链路通过。笔输入使用 Chromium pen 事件，未将其表述为实体数位笔验收。

真实网关的公式画笔识别 3 例功能链路通过，2 例精确匹配；剪贴板识别 8 例功能链路通过，2 例精确匹配。其中 Math Academy 两例分别将 `x` 识别为 `X`，因此精确匹配为 0/2。将这两份实际识别输出粘贴到网页后，输入器分别回读 `\frac{X+1}{2}` 和 `\sqrt{X+1}`，结构及大小写与应用输出一致。客户端没有擅自将 `X` 改为 `x`。

网页共核对 13 份输出（11 组确定性样本加 2 份真实 OCR 输出），全部兼容；确定性样本与冻结发行包输出逐字一致。测试全程未提交答案，输入框最终为空。

## 使用范围

用户仍需点击网页公式输入框并按 Ctrl+V，自行核对后提交。识别转写可能出现大小写差异；格式兼容通过不代表 OCR 每次精确匹配。网站升级输入器后需重新核对兼容性。
