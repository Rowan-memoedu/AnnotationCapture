# 白板菜单、光标与进入速度

Windows 全屏批注走 FocusToolWin 的 GDI 截图方法。启动时只预热读图进程，进入批注时才取屏幕像素，使用无损传输。原生取图不可用时使用 Electron 的屏幕截图入口。

左侧白板主按钮保留原有点击行为。悬停后向右显示一列四项。验收覆盖显式等待智能白板、强制中央白板、矩形反选和有凹口的自由反选，也检查了切换、撤销恢复和公式笔迹范围。

光标分开检查。Windows 桌面测试用实际系统光标的不透明像素对比原生帧。课页重放检查白板出现前后的箭头像素、旁边的题目文字和收起白板后的还原。独立样本检查不同缩放和没有光晕的数学字形。

进入速度在同机的两个 Windows 发行包上测量，从触发全屏批注到画布可以书写。计时读取真实屏幕，不保存计时用截图。具体运行次数、中位数和本次回归范围见发行附件 `build-info.json`。
