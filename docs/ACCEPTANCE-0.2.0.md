## 新 API 真实识别

在实际编辑器中用鼠标书写，提交独立选定的笔迹图。转写提示不包含预期答案，不修改大小写、不求解或简化表达式。

| 样例 | 实际返回 | 结果 |
| --- | --- | --- |
| 多项式 | `x^2+1=0` | 精确匹配，剪贴板一致 |
| 分式 | `\frac{x+1}{2}` | 精确匹配，剪贴板一致 |
| 根式 | `\sqrt{x+1}` | 精确匹配，剪贴板一致 |
| 大小写 | `X+x=2` | 大小写均保留，剪贴板一致 |

模型为 `deepseek-flash`，低强度推理，最终 ZIP 的四次实际请求耗时约 3.0–4.7 秒。多项式同时验证了修改结果、重新复制和保留原始识别值。普通受邀账号也独立完成同一服务的真实识别。

## 升级条件与限制

- 覆盖前须先从托盘退出旧版，等待程序退出后再覆盖全部程序文件。只关闭设置窗口不会退出后台进程。
- 保留原 `AnnotationCapture-data`、自定义归档目录和快捷方式参数；升级无需卸载、清空目录或迁移历史图片。
- 0.1.1 的个人 API 设置不再用于识别。升级后首次输入邀请码，后续覆盖更新保留登录。
- 本机 `Alt+W` 已被其他程序占用，系统拒绝注册；原生全屏快捷键使用可用的 `Alt+Shift+W` 验收通过。发行版默认仍为 `Alt+W`，冲突时可在设置中修改。
- 验收期间出现过一次显卡进程退出，以及窗口隔离和异步绘制读取时序造成的测试失败。失败记录保留，修复测试时序后只复验失败阶段；通过记录不替代任意设备的兼容性保证。
- Math Academy 输入器适配、多显示器组合、其他 Windows 真机和实际手写笔体验尚未验收；强制终止或断电时的未完成画布恢复尚未实现。
- 本机验收与 GitHub Actions 分别报告；本版没有商业代码签名。

早期版本验收见 [0.1.1 记录](ACCEPTANCE.md)。私密截图、邀请码和运行配置不发布到源码或 Release。
