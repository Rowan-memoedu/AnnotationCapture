# 启动配置保留

修正 Windows 注册表写入：仅在键不存在时创建键，随后只修改 AnnotationCapture 自身的值，保留其他应用的启动命令与启用、禁用状态。自启动测试改用独立的临时注册表分支，逐次检查其他应用的模拟值和禁用标记未变。

验证包含类型检查、代码检查、110 项单元测试、16 项原生自启动检查及独立 Windows 发行包冷启动。普通测试模式不修改启动配置，迁移保留已关闭的选择，任务创建失败时回退到普通启动入口。

维护时优先复用已验证的命令行交付脚本与安装目录内的 `resources/update-worker.ps1`，依次执行 `Prepare`、`Apply` 并核验健康回执、运行进程、文件哈希、登录设置与归档。没有应用启动参数不代表缺少这条更新链路。真实 Windows 注销登录或整机重启仍未在本次验收中执行。
