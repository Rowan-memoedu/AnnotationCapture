# 0.6.0 验收

## 压感画笔

使用 perfect-freehand 1.2.3，根据笔事件的真实压力生成填充轮廓，关闭速度模拟。鼠标和关闭笔压后的笔沿用原等宽画笔。设置中的笔压默认开启，灵敏度范围为 1–100，默认 50；保存后对下一次批注生效。

冻结的独立程序通过 Electron/CDP 笔事件验证 100%、150%、200% 显示缩放。在基础粗细为 14 时，轻压与重压分别产生约 10、20 像素宽的笔迹，鼠标两条均为 14 像素。灵敏度 10 与 100 的轻重线宽差分别为约 2、20 像素；单条连续笔迹可随压力变粗细。

验证覆盖开关关闭、采样点合并、抬笔不插入零压力、中断后继续书写、橡皮擦、撤销重做、粗笔内部圈选、公式转换颜色与原始笔迹保留，以及落笔期间请求归档时等待抬笔。原始压力点和橡皮遮罩随画布 JSON 保存；几何单元测试覆盖序列化恢复和移动、旋转、缩放后的粗细调整。

自动化输入验证了应用接收与绘制压力的链路，未连接真实压感笔或数位板完成硬件实测。具体设备须由笔、数位板及驱动提供压力数据；固定压力值无法产生力度变化。

## 设置与既有功能

实际 Electron 设置页通过默认值、开关禁用状态、非法输入拒绝、IPC 参数校验、保存后重启和旧配置兼容检查。界面在 320、375、414、768、1440 像素宽度下无横向溢出。

类型检查、Lint 和 90 项单元测试通过。独立 ZIP 通过 33 个发行验收阶段，包括全屏与区域截图、文字编辑、连续书写、滚轮粗细、D 键圈选与清除、撤销重做、公式排版与编辑、保存失败恢复、快捷键、复制后保持画布、存档保留、Math Academy 输出，以及三档显示缩放。原有连续书写性能检查覆盖两种截图入口各 120 条笔迹。

初次验收遇到缩放后的测试轨迹越界、底部像素取样越界和外部剪贴板变化，脚本已修正坐标、取样边界及结果保留分支，保留实际复制状态。另有渲染进程退出和内存分配失败；当时系统提交内存达 99%，恢复后在同一冻结 ZIP 上重跑失败项并通过。未降低功能判定标准，也未替换已冻结程序。

## 真实识别

压感输入另行通过普通画笔、公式画笔及自由截图选区三条真实 OCR 链路。预览包含笔迹，空白选区被拒绝，发送图只含笔迹与白底，三次结果均成功复制；其中 2/3 转写完全一致，另一例将大写 `X` 识别为小写 `x`。

原鼠标输入的同组三条链路为 2/3 精确匹配；八个公式与输出格式样例为 5/8 精确匹配，其余同为 `x/X` 大小写差异。普通文字、Markdown、公式和 Mermaid 自动识别，以及两种手写流程图结构检查通过。保留服务返回原文，未将期望答案写回识别结果。

压感轮廓与公式转换的隔离回归使用固定识别响应来检查颜色、归档和撤销行为；上述真实 OCR 检查独立调用识别服务，不使用固定响应。功能链路通过与转写精确匹配分别记录。

## 发行与更新

Windows x64 ZIP 内含运行时、公式字体和 perfect-freehand 的 MIT 许可。发行审计未发现外部 node_modules、用户截图、运行配置或凭据；73 个程序文件有 SHA-256 清单。源码、发行页和下载页使用同一版本。

本机更新通过已有原生更新工作器执行 Prepare/Apply，使用公开下载包并校验 SHA-256。安装结果另行核对健康回执、实际运行 PID、全部程序文件和原登录设置、历史归档的哈希；该安装方式不作为每日自动检查和自动下载流程的新增验收。
