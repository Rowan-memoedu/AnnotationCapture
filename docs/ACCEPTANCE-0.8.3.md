# 登录后后台启动

程序使用当前用户的 Windows 登录任务，在登录约 10 秒后后台启动，避开普通启动项队列。右键托盘的“开机自启动”可开关；升级保留旧注册表启动项、启动快捷方式及已有任务的关闭状态。迁移成功后停用旧入口，属于本程序的旧快捷方式保留可恢复副本。

类型检查、代码检查及 110 项单元测试通过。Windows PowerShell 5.1 实测包含首次注册、启停与重启保留、中文和特殊字符路径、安装位置修复、删除任务后的关闭状态保留、旧入口迁移，以及注册失败回退。独立 Windows 发行包验证了无可见窗口启动、三组快捷键、开关跨重启保留，以及计划任务直接冷启动。

尚未实测修复后的真实 Windows 注销登录或整机重启。10 秒为任务配置延迟，系统负载仍可能影响实际启动耗时。详细验证范围见发行附件 `build-info.json`。
