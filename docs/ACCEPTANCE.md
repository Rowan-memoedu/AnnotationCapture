## DeepSeek 真实识别

使用 `deepseek-flash`，启用低强度推理，只提交框选后的笔迹图，没有提交截图背景或预期答案。只将最终公式内容复制到剪贴板。

| 样例 | 预期 | 实际返回 | 精确匹配 |
| --- | --- | --- | --- |
| 多项式 | `x^2+1=0` | `x^{2}+1=0` | 通过 |
| 分式 | `\frac{x+1}{2}` | `\frac{x+1}{2}` | 通过 |
| 根式 | `\sqrt{x+1}` | `\sqrt{x+1}` | 通过 |
| 独立大小写样例 | `X+x=2` | `X+x=2` | 通过，大写与小写均保留 |

四项都完成真实 API 请求，公式精确匹配且剪贴板与返回文本一致，独立程序响应约 4.1–5.2 秒。多项式同时验证了编辑结果、重新复制以及原始识别值保留。四个样例通过不代表任意笔迹均能正确识别，使用时仍应核对结果。

0.1.0 的分式、根式曾出现 x / X 混淆，原始失败图和记录保留。0.1.1 只调整通用 API 推理配置，未修改转写 Prompt、预期答案或字母大小写规则；先在冻结输入上验证，再对重新绘制的三个回归样例和一个独立大小写样例验收。没有把大写输出统一改成小写，也没有重试抽取某次碰巧正确的结果。

## 保留边界

- Math Academy 浏览器、公式输入器与粘贴适配按用户要求暂缓。
- 多显示器组合、其他 Windows 设备、真实手写笔体验未做真机验收。
- 强制终止和断电时的未完成画布恢复未实现。
- 当前运行中的结果列表不跨重启恢复，但原始图和结果 JSON 均保存在归档目录。
- 整份上游源码的类型检查仍有 `xtimelog` 第三方源码错误；当前应用的类型检查独立通过。上游选区尺寸计算保留了经字符限制的 `eval`，构建会提示警告；它只处理用户本机输入的尺寸表达式。
- 应用构建与功能测试尚未通过 GitHub Actions 运行；静态下载页由 GitHub Pages 单独部署。上游自动发布工作流已移入参考目录，避免生成与本发行版不一致的包。
- 本版未做商业代码签名。

完整本机证据保存在开发任务的验收产物目录，包含原始失败样例；含桌面背景的截图不会发布到源码或 Release。
